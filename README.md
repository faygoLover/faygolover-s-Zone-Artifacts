# faygolover's Zone Artifacts

Мод для **Minecraft 1.20.1 (Forge)**: аномалии в духе S.T.A.L.K.E.R. для ролевых серверов — Электра, Жарка,
гравитационные ловушки, кислотные лужи, пси-поля, блуждающие шаровые молнии и ещё два десятка видов. Каждую
аномалию ведущий (ГМ) ставит руками там, где нужно по сюжету, и настраивает прямо в игре: размер, силу, урон,
перезарядку, внешний вид.

*A Forge 1.20.1 mod with S.T.A.L.K.E.R.-style anomalies for roleplay servers, placed and tuned in-game by the game
master. Interface in Russian and English.*

Сделан для Full RP сервера «Департамент». Артефакты, пояса и защита от аномалий — в планах.

## Возможности

- **30+ аномалий**: зоны (ловушка стоит на месте), маршрутные (шар летает по точкам и может гнаться за целью) и
  аномалии-блоки. У каждой свои урон, эффекты, звук и вид.
- **КПК аномалий** — один предмет для всех настроек: ПКМ по аномалии открывает окно с ползунками, галочками и
  кнопками. Размер (у многих зон — отдельно ширина, высота и длина), сила, урон, перезарядка, насыщенность
  эффектов; сдвиг, выключение, «без урона», «без звука», «невидимая», удаление.
- **Мобы тоже попадают** в аномалии и убегают от них после удара.
- **Без миксинов и своих шейдеров** — всё на событиях Forge, поэтому с другими модами уживается проще.
- Стандартные настройки новых аномалий и лимиты — в конфиге сервера.

## Аномалии

**Зоны**

| Электра | Бьёт током всё, что вошло в зону; разряды с поверхностей вокруг. |
| Жарка / Иней | Жжёт / морозит, пока в зоне кто-то есть; пламя, изморозь, меняет блоки. |
| Разлом / Холодный разлом | Трещины в земле, из которых в цель бьёт струя пламени (холодного огня). |
| Комариная плешь | Вжимает в землю и швыряет. |
| Воронка | Затягивает по спирали и разрывает. |
| Карусель | Раскручивает, выбрасывает и бьёт волной сжатого воздуха. |
| Подушка | Безвредна: гасит падение и подбрасывает. |
| Лифт | Поднимает и держит в воздухе, потом выталкивает. |
| Кисель | Светящаяся кислотная лужа: растворяет предметы, разъедает обувь, растекается. |
| Кислотный туман | Стоит над землёй и выбрасывает едкие струи. |
| Амёба | Желе-лужа: собирается в шар, надувается и лопается кислотным облаком. |
| Трясина | С виду обычная земля, в которой медленно тонешь. |
| Дымка | Туман, в котором глохнут звуки и слышится что-то далёкое. |
| Сумрак | Густой мрак: снаружи не видно, кто внутри; внутри почти ничего не видно и не слышно. |
| Пси-зона | Голоса в голове, плывущее зрение, тяжёлые ноги. |
| Маковое поле | Навевает сон, из которого можно не проснуться. |
| Ржавчина | Ржавый мох и едкая пыль под ногами; иногда пятно раскаляется и взрывается. |
| Мыльные пузыри | Парящие пузыри, которые лопаются цепной реакцией. |
| Хлопушка | Вспыхивает перед глазами, ослепляет и обжигает. |
| Светлячок | Блуждающие огоньки (атмосфера). |
| Камертон | Облако стеклянных игл: режет того, кто движется внутри. |
| Фантомный свет | Ряды призрачных огней, заметных только издалека. |

**Маршрутные** — шар летает по точкам, которые ставит ГМ, и может преследовать цель: Тесла (шаровая молния),
Комета, Холодная комета, Химическая комета (оставляет ядовитое облако), Грави.

**Блоки и прочее**: Жгучий пух (свисает со стен и стреляет спорами), Ёжик (иглы, растущие из блока),
Паутина (почти невидимые нити между точками, режут при касании).

## Установка

1. Minecraft **1.20.1**, **Forge 47.4** или новее, Java 17.
2. Положите `fl_zone_arts-<версия>.jar` в папку `mods` — **и на сервере, и у каждого игрока**.
3. На сервере включите `allow-flight=true` в `server.properties`: гравитационные аномалии и Лифт поднимают игроков
   в воздух, иначе сервер выкинет их за «полёт».

## Как пользоваться (для ГМ)

- Всё — во вкладке творческого инвентаря **«Zone Artifacts: Аномалии»**.
- **Установщики** (по одному на аномалию): ПКМ по блоку — поставить, ЛКМ по зоне — убрать. С установщиком в руке
  видны границы зон этого типа. Маршрут ставится по точкам: ПКМ по блоку — точка, ПКМ по первой точке — замкнуть,
  ЛКМ по точке — убрать её или весь маршрут.
- **КПК аномалий**: ПКМ по аномалии — окно настроек. Ползунки и кнопки −/+ (стандартное значение — в подсказке),
  сдвиг на блок по осям, «Удалить» (с подтверждением) и галочки:
  - «Включена» — выключенная ничего не делает и не видна, но остаётся на месте;
  - «Урон» — для безопасной сцены: всё работает, но никто не получает урон;
  - «Звук» и «Видимость» — невидимая аномалия работает как ловушка, но не рисуется;
  - «На ГМ» — действует и на игроков в творческом режиме и наблюдателей (по умолчанию не трогает их).

  Что меняет каждое поле у каждой аномалии — в [docs/parameters.md](docs/parameters.md)
  (то же [таблицей Excel](docs/parameters.xlsx)).
- **Команды** (права уровня 2):
  - `/fl_zone_arts electrify <цели> <секунды> [урон]` — «электризация» (визуально; с уроном — удар током);
  - `/fl_zone_arts tesla list` и `/fl_zone_arts tesla cleanup` — список маршрутов; удалить незавершённые и брошенные;
  - `/fl_zone_arts tesla flag <игрок> <true|false>` — Тесла преследует игроков с этим флагом.
- **Конфиги**: `config/fl_zone_arts-common.toml` (сервер) — стандартные настройки новых аномалий и лимиты КПК;
  `config/fl_zone_arts-client.toml` (у игрока) — потолок насыщенности эффектов и искажение воздуха (для слабых ПК).
  Изменение стандартов не трогает уже поставленные аномалии.

## Сборка из исходников

```bash
./gradlew build        # мод: build/libs/fl_zone_arts-<версия>.jar
./gradlew runClient    # запустить Minecraft с модом для проверки
```

На Windows — `gradlew.bat`. Нужен JDK 17. Первая сборка скачает Minecraft и Forge (10–20 минут).
В `tools/` — скрипты, которыми сделаны иконки (Python + Pillow) и часть звуков (numpy, scipy, soundfile).
