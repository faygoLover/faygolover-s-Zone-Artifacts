# Жарка и Иней — спецификация (0.1.6.0)

Термические аномалии-зоны (как Электра: `AnomalyInstance` в `AnomalySavedData`, ставятся установщиками `zharka_placer` / `iney_placer`, настраиваются тюнерами).

## Механика (сервер, `ThermalEngine`)
- **Активна**, пока в зоне есть живое существо (не наблюдатель, не игрок в творческом). Флаг `active` синхронизируется с клиентом при смене (`SyncAnomalyCooldownPacket` несёт onCooldown + active).
- **Урон — общий таймер**: первый удар через 0,2 с после активации, дальше раз в `cooldownSeconds` (тюнер перезарядки = «интервал урона», от 0.1 с, шаг 0.1 / Shift 1.0; хранится как double), по всем внутри. Перед каждым ударом `invulnerableTime = 0`, чтобы кадры неуязвимости не съедали частые удары. Сбрасывается, когда зона пустеет.
- **Типы урона**: `scaling: never` у всех (`anomaly_*`) — иначе на мирной сложности урон по игрокам обнулялся (баг 0.1.5.0).
- **Жарка**: `anomaly_heat` (effects `burning`, тег `minecraft:is_fire`), шанс `zharka.igniteChance` (0.25) поджечь на `igniteSeconds` (3). Снимает заморозку.
- **Иней**: `anomaly_cold` (effects `freezing`, тег `minecraft:is_freezing`); каждый тик +`iney.freezePerTick` (4) к ванильному замерзанию. Тушит горящих.
- **Блоки** (пока активна, зона + `thermal.blockRadius` = 2): раз в 10 тиков выборка ~5 % объёма, каждый блок в среднем раз в ~10 с.
  - Жарка: лёд тает поэтапно → вода → испарение; снег тает; водонаполненность снимается; дёрн → тропа; пашня/мицелий → земля; подзол → каменистая; грязь → утрамбованная; илистые корни → мангровые; мокрая губка → губка; глина → терракота; костры/свечи зажигаются; огонь у горючего (1/3).
  - Иней: вода → лёд; лава → обсидиан/булыжник; огонь и костры/свечи гаснут; листва исчезает; растения гибнут / → сухой куст. **Снег — только внутри самой зоны**, слой появляется 1 раз из 12 выборок (~2 мин), растёт 1 из 18 (~3 мин), до 3 слоёв.
  - Выключатели `zharka.altersBlocks`, `iney.altersBlocks`.

## Визуал и звук (клиент, `client/thermal`)
- Активность 0..1: разгон 0,2 с, затухание 3 с.
- Частицы: `ember`, `heat_smoke`, `frost_mist` + ванильные снежинки. Долгоживущие, с граней блоков зоны.
- Иней: кристаллы-звёздочки на гранях (`IneyFrostRenderer`), ярче при активности.
- Звук: петля `zharka_idle`, громкость/тон по активности (`ThermalLoopSound`); Иней — редкие ванильные звуки замерзания; `iney_enter` в момент активации.

## Тюнер дистанции наведения (0.1.6.0)
- `targeting_tuner`, `TunerKind.TARGETING` (последний в enum — передаётся по ordinal). У маршрутов — `TeslaRoute.chaseRadius` (0 = не преследует). У зон с 0.1.34.0 — `AnomalyInstance.range` (Хлопушка, Светлячок).
