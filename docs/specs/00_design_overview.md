# fl_zone_arts — Дизайн аномалий (черновик, этап 1)

> Исторический документ (первая волна обсуждения, до 0.1.3.0). Часть решений позже изменена:
> датапаков больше нет (всё — тюнеры + TOML-конфиг), шкалы радиации/пси ещё не реализованы.
> Актуальное поведение — в остальных файлах `docs/specs/` и в README.

Проект: Minecraft Forge 1.20.1 (47.4.10), modid `fl_zone_arts`, пакет `faygolover.zoneartifacts`,
название "faygolover's Zone Artifacts". Для сервера "Департамент" (Full RP, Control/SCP сеттинг).
Артефакты, пояса, сопротивления, аномальная энергия — временно отложены, обсуждаются отдельно.
Этот документ — только про аномалии: типы, установка, общий движок, шкалы.

## Общая архитектура (исходный замысел)

- Java-ядро: движок зон, примитивы эффектов, синхронизация с клиентом, шкалы игрока.
- Конфиг (TOML) — глобальное: лимиты, стандарты, включение фич.
- Действительно уникальная логика — отдельные Java-классы.

## Установка ГМом

- **Предмет на каждый тип аномалии.** ПКМ по грани блока — ставит аномалию **снаружи**, рядом с
  этой гранью (как обычный блок). ЛКМ по зоне — убирает.
- **В руке подсвечивает зону действия**: единая полупрозрачная область с непрозрачными рёбрами.
- **Вейпоинты** (Тесла и прочие маршрутные): отдельный предмет-строитель маршрута. ПКМ — точки,
  ПКМ по стартовой — замкнуть и заспаунить; ЛКМ — удалить точку/маршрут. Черновики жёлтые, готовые —
  цвет типа. `/fl_zone_arts tesla cleanup` сбрасывает зависшие черновики и осиротевшие маршруты.

## Накопительные шкалы игрока (радиация, пси) — НЕ РЕАЛИЗОВАНО

- Единый capability с именованными шкалами (radiation, psi, …). Чем выше — сильнее периодический урон.
  Медленно спадают. Сначала только команды `/fl_zone_arts gauge get|set`. UI позже (PDA / мод медицины).
- Задел: Сумрак, Фантомный свет (взгляд > 3 с), Пси-зона в будущем будут поднимать пси.

## Первоначальный список аномалий (первая волна)

Электра, Тесла, Жарка, Иней, Кисель, Холодец, Газировка, Лифт, Карусель, Хлопушка, Жгучий пух,
Пси-зона, Воронка, Трамплин. Холодец, Газировка, Трамплин — ещё не сделаны.
Отложены (экзотика): Смещение, Петля, Эхо.

## Прочие решения из обсуждения

- Кисель/Холодец/Газировка задумывались как меш по контуру занятых ячеек (marching squares) —
  Кисель в итоге сделан как лужа-зона с процедурным неровным краем.
- Тесла: преследует любую живую сущность в радиусе погони (тюнер дистанции наведения), неуязвима,
  pass-through (`isPickable()=false`, `canBeHitByProjectile()=false`).
