# Третья волна аномалий

Статус: группы 1–3 — **0.1.28.0** (Трясина, Дымка, Сумрак, Пси-зона, Маковое поле, Ржавчина, Ёжик);
группы 4–5 — **0.1.34.0** (Мыльные пузыри, Хлопушка, Светлячок, Камертон, Паутина, Фантомный свет).
**Код волны ни разу не компилировался и не тестировался в игре** — ожидаются правки.
Протокол сети 14 (SyncAnomaliesPacket.Entry: + cooldown, damage (0.1.28), + range, yaw (0.1.34)).
Звуки синтезированы (`tools/sounds/gen_0128.py`, `gen_0134.py`).

## Общий каркас (клиент, без миксинов)
- `client/fx/SoundFx`: PlaySoundEvent оборачивает каждый новый нетикающий звук (кроме MASTER/MUSIC/RECORDS и собственных гулов)
  в Tickable-обёртку, громкость/тон которой каждый тик берутся от Дымки, Сумрака, Трясины, Макового поля, вспышки Хлопушки.
  Тикающие звуки не оборачиваются (иначе ломаются stop/isActive по идентичности).
- `client/fx/ScreenFx`: туман (ViewportEvent.RenderFog/ComputeFogColor — Дымка серая, Сумрак чёрный), оверлей «под всем»
  (registerBelowAll "senses"): пси-эффекты (копия кадра: колыхание сеткой, R/B через colorMask, 4 смещённых прохода — размытие),
  чёрный (Трясина/Сумрак/полный сон), белая вспышка (Хлопушка), веки (Маковое поле).
- `client/fx/HumLoop`: «звук в голове» (relative, без затухания).
- Размер новой зоны по умолчанию свой для типа (`AnomalyDefaults.size`); `AnomalyInstance.range` (тюнер дистанции наведения для зон,
  `AnomalyDefaults.range`) и `yaw` (куда смотрел ГМ при установке) сохраняются и синхронизируются.

## Трясина (`tryasina`)
- Ставится **в кликнутый блок**; `Swamp.region`: верх = верх блока, вниз на size, в стороны size/2 (`AnomalyGeometry.zoneAabb(typeId,…)`).
- Столбцы (`Swamp.Columns`, скан раз в 40 тиков): сплошные блоки (isCollisionShapeFullBlock) от поверхности вниз до первой пустоты, ≤ глубины зоны.
- `SwampPhysics`: в трясине `noPhysics=true`; после движения — своя коллизия (все блоки кроме разжиженных + «пол» на глубине depth), шаг-подъём.
  depth += sinkSpeed(0.12)·speed/20, пока стоит на полу; у края depth ≤ 0.7·(расстояние до края − полуширина); быстрее подъёма к краю не пройти;
  подъём 0.08/тик. Мобы — сервер (LivingTickEvent → LevelTickEvent END), игрок — свой клиент (LivingTickEvent → PlayerTickEvent END);
  серверному игроку только noPhysics (заодно нет «moved wrongly» и удушья в блоке).
- Голова под поверхностью: урон `anomaly_swamp` (bypasses_armor) = damage раз в cooldown; экран чёрный; звуки ×0.25.
- Клиент: беззвучные шаги (".step" над трясиной), круги от движения/приземления, лёгкий глянец под скользящим углом. Хлюпанье `swamp_squelch`.

## Дымка (`dymka`) — только клиент
- Снаружи серые пуффы; внутри туман до visibility·3/intensity (≥1.5), цвет от освещения; звук ×(1−0.65k), тон ×(1−0.1k±);
  далёкие звуки `dymka_distant` (4 варианта, attenuation 48) в 15–30 бл. раз в 8–20 с. Без миксинов (решение пользователя).

## Сумрак (`sumrak`) — только клиент
- Чёрные FramePuff на сетке (шаг ≥1.1, ≤~380 пуффов), края курятся. Сущности внутри не рисуются для камеры снаружи (+ ники).
  Внутри: чёрный туман (1.2 бл.), оверлей 0.88, звуки ×0.05, гул `sumrak_drone`. Звуки изнутри для внешних ×0.05.
  Безвреден (позже — пси-составляющая).

## Пси-зона (`psi_zone`)
- Сервер (`PsiEngine`): PathfinderMob внутри раз в секунду уводятся навигацией наружу (0.9).
- Клиент: вход — пауза 10 тиков, нарастание 10; выход так же. Замедление ввода slowdown(0.35)·intensity/3, гул, шёпот,
  экран: колыхание + расслоение + волны размытия раз в cooldown (6 с).

## Маковое поле (`poppy_field`)
- Сервер (`PoppyEngine`): раз в cooldown внутри счётчик +1 → микросон; снаружи −1 с той же частотой. На intensity — ASLEEP:
  через fullSleepSeconds урон `anomaly_sleep` (bypasses_armor) = damage (1000), повторно пока спит. Удар от сущности по спящему — −2.
  Фазы NONE/EPISODE/ASLEEP/WAKING (CLOSE 24, OPEN 14, WAKE 24 тика). Мобы — то же (goal/target control flags отключаются).
- Клиент: веки, чёрный, гул, ввод вперёд/заблокирован, взгляд удерживается; спящие ложатся на спину (RenderLivingEvent Pre/Post, LOWEST). Хитбокс не меняется.
- Маки — кросс-квады `block/poppy` (≤3000) на AFTER_CUTOUT_BLOCKS, лепестки — частица `poppy_petal`, рои по траекториям.

## Ржавчина (`rust`)
- Мох на открытых гранях полных блоков (коврик + 2 слоя ворса, UV тайлится по миру), пыль у ног → ChemClouds. После cooldown (60 с) облачко с шансом 25 %
  заряжено → пятно (1 на аномалию, r 1.5, 5 мин, 3 с нагрев). Наступил → `anomaly_rust` 14, огонь 2 с, ожог, броня −40 %. Снежок — остужает.

## Ёжик (блок `ezhik`)
- На любую грань; BER: бугор + до 90 игл по спирали с текстурой/оттенком блока-носителя (getQuads + BlockColors); рост/опадание, дрожь, пульс.
  Тюнеры: радиус, число, скорость (`TunerService.tuneEzhik`). Атмосферный, без урона.

## Мыльные пузыри (`soap_bubbles`)
- Сущности `soap_bubble` (0.8, не сохраняются). Дрейф (скорость ×тюнер), отталкивание друг от друга и блоков, возврат в зону.
  Касание их bbox любой сущностью / hurt() (снежок, стрела, удар) → заряд 5 тиков → удар: радиус = clamp(1.2+0.2·damage, 1, 6),
  урон damage·(0.4…1) (`anomaly_gravity`), толчок; пузыри в радиусе — заряд 3 тика (цепь, в т.ч. соседние зоны).
- Спаун: первый через cooldown, затем по одному раз в respawnSeconds (2) до intensity; после взрыва пауза cooldown заново.
- Клиент: плёнка с радужным краем и бликом (GlowRenderType), шиммер-линза, `BubblePopPacket` — вспышка, частицы, волна.

## Хлопушка (`khlopushka`)
- Раз в cooldown при игроке в зоне — сгусток в 3–4.5 бл. перед взглядом случайного игрока (или у блока), заряд chargeSeconds/speed,
  взрыв: `anomaly_heat` damage·(1 − ⅔·d/R), R = blastRadius (3); вспышка — смотревшим (угол ≤55°, прямая видимость) ближе range (10):
  игроку `KhlopushkaPacket.FLASH` (белый экран, звон `khlopushka_ring`, глухота), мобам Слепота. Длительность blindSeconds·intensity/3.

## Светлячок (`svetlyachok`) — только клиент
- intensity огоньков, петли-синусоиды по зоне, высота над землёй ≤ range (2.5), скорость ×speed; мерцание/притухание, пятно на земле.

## Камертон (`kamerton`)
- Шар диаметра size. Движение (не присед, скорость > 0.03) → `anomaly_cut` (броня работает) раз в cooldown (0.5 с), бег ×sprintMultiplier.
  Летящие снаряды в шаре — discard + осколки стекла + `kamerton_shatter`. active при движении внутри → звон громче.
- Клиент: до 1500 игл в 6 слоях (Фибоначчи-сфера), стекло alpha + блик аддитивно (сбоку и мерцание), раздвигаются вокруг тел; шиммер.

## Паутина (`pautina`)
- `WebSavedData` (по измерению): паутины = списки нитей (точки кликов, не блоки), damage/regrow/intensity на паутину.
  `WebPlacerItem`: ПКМ цепочкой, Shift+ПКМ — закончить, ЛКМ по нити (клиент, `WebEditPacket`) — убрать нить / Shift — паутину.
- `WebEngine`: живое пересекает нить (AABB.clip) → `anomaly_web` (bypasses_armor), нить рвётся на regrowSeconds (30);
  `SyncWebsPacket` (полная, при входе/смене измерения/правках), `WebStrandPacket` (обрыв/отрастание). Снежки нить игнорирует.
- Клиент: аддитивные ленты 0.016; альфа = 0.015 + свет²·(блеск сбоку + бегущие искры); + луч предмета из `web.lightItems` (конус ~20°, 20 бл.);
  с установщиком/тюнером ≥0.35. Тюнер наводится на нить (синтетическая запись с typeId WEB, id в x).

## Фантомный свет (`fantom_light`) — только клиент
- 5 линий через size/4 поперёк yaw установки, высота size (крайние 0.62, приподняты), огоньков 4+2·intensity; мерцание пламени/дуги;
  альфа = smoothstep((dist − goneAt 16)/(fullAt 30 − goneAt)), видимость до 220 бл., glow масштабируется с расстоянием.
  Позже — пси-составляющая.
